# ฝึกแผนที่และเข็มทิศ · เว็บแอปของหน่วย

เว็บแอปฝึกการใช้แผนที่และเข็มทิศเลนเซติก 4 ชุด (แบบฝึกเต็ม/ย่อ และเกมเต็ม/ย่อ) สำหรับมือถือและแท็บเล็ต
ผู้รับการฝึกสแกน QR แล้วใช้ได้ทันที ไม่ต้องสมัคร ไม่ต้องติดตั้งแอป ไม่ต้องมีบัญชีใด ๆ
คะแนนส่งเข้า Google Sheet ของครูฝึกเองทุกครั้งที่จบโมดูลหรือภารกิจ

ค่าใช้จ่าย: ไม่มี (ใช้บัญชี Google ของครูฝึก และโฮสต์เว็บฟรี)
เวลาติดตั้งครั้งแรก: ประมาณ 30 นาที

## ขั้นที่ 1 · สร้าง Google Sheet รับคะแนน (10 นาที)

1. เปิด <https://sheets.new> ด้วยบัญชี Google ของครูฝึก ตั้งชื่อไฟล์ เช่น `คะแนนฝึกแผนที่-เข็มทิศ`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในหน้าแก้ไขทั้งหมด เปิดไฟล์ `apps-script/Code.gs` คัดลอกทั้งหมดไปวาง แล้วกด **💾 บันทึก**
4. ที่แถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **▶ เรียกใช้**
   - ครั้งแรก Google จะขอสิทธิ์: กด **ตรวจสอบสิทธิ์** → เลือกบัญชี → **ขั้นสูง** → **ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต**
     (ขึ้นคำว่าไม่ปลอดภัยเพราะเป็นสคริปต์ที่ครูฝึกเขียนเอง ไม่ได้ผ่านการตรวจของ Google เป็นเรื่องปกติ)
   - กลับไปที่ชีต จะมีแผ่นงานใหม่ 4 แผ่น: `สรุป-แบบฝึก` `สรุป-เกม` `บันทึกทั้งหมด` `ภาพรวม`
5. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - กด ⚙ ข้าง "เลือกประเภท" → **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (สำคัญ ถ้าไม่ตั้ง ผู้รับการฝึกจะส่งคะแนนไม่ได้)
   - กด **ทำให้ใช้งานได้** แล้ว**คัดลอก URL เว็บแอป** (ลงท้ายด้วย `/exec`)
6. ทดสอบ: วาง URL ในเบราว์เซอร์ ต้องเห็นข้อความ `{"ok":true,"service":"landnav-scores",…}`

## ขั้นที่ 2 · ใส่ที่อยู่ส่งคะแนนใน config.js

เปิด `config.js` ด้วยโปรแกรมแก้ข้อความ (Notepad, TextEdit) แล้ววาง URL จากขั้นที่ 1 ระหว่างเครื่องหมาย `'…'`

```js
window.LNAV_CONFIG = {
  SCRIPT_URL: 'https://script.google.com/macros/s/AKfy…/exec',
  UNIT: 'แผนกวิชาการดำรงชีพ · โรงเรียนการบิน กองทัพอากาศ'
};
```

## ขั้นที่ 3 · นำเว็บขึ้นอินเทอร์เน็ต (เลือก 1 ทาง)

### ทาง A · GitHub Pages (แนะนำ ลิงก์ถาวร ฟรี)

1. สมัครบัญชีที่ <https://github.com> (ครั้งเดียว)
2. กด **+ → New repository** ตั้งชื่อ เช่น `landnav` เลือก **Public** → **Create repository**
3. กด **uploading an existing file** แล้วลาก**ไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้** (ไม่ใช่ตัวโฟลเดอร์ `landnav-web`) ไปวาง → **Commit changes**
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, โฟลเดอร์ **/ (root)** → **Save**
5. รอ 1–2 นาที ที่อยู่เว็บจะเป็น `https://ชื่อบัญชี.github.io/landnav/`

อัปเดตภายหลัง: เปิด repository → **Add file → Upload files** ลากไฟล์ที่แก้แล้วทับ → Commit

### ทาง B · Netlify Drop (เร็วที่สุด)

1. เปิด <https://app.netlify.com/drop> แล้วลากโฟลเดอร์ `landnav-web` ทั้งโฟลเดอร์ไปวาง
2. สมัครบัญชีฟรีเพื่อให้เว็บอยู่ถาวร (ถ้าไม่สมัคร เว็บจะถูกลบในไม่กี่ชั่วโมง)
3. ตั้งชื่อเว็บได้ที่ **Site configuration → Change site name** เช่น `rtaf-landnav.netlify.app`

## ขั้นที่ 4 · ทดสอบก่อนใช้จริง (10 นาที)

1. เปิดหน้าแรกของเว็บ → **สำหรับครูฝึก** → **ทดสอบการเชื่อมต่อ Google Sheet** ต้องขึ้น "เชื่อมต่อได้ ✓"
2. ใช้มือถือ (ไม่ต้องล็อกอินอะไร) เปิดแบบฝึกชุดย่อ กรอกชื่อทดสอบ ฝึก 1 โมดูล
3. แท็บ **ผลการฝึก** ต้องขึ้น "ส่งคะแนนถึงครูฝึกแล้ว ✓" และในชีต `สรุป-แบบฝึก` มีแถวใหม่ ร้อยละคำนวณถูก
4. ทำซ้ำกับเกม 1 ภารกิจ ดูแผ่น `สรุป-เกม`
5. ลบแถวทดสอบในชีต (ลบทั้งแถว ห้ามลบแถวหัวตาราง)

## ขั้นที่ 5 · พิมพ์โปสเตอร์ QR

เปิด `https://…/poster.html` (หรือหน้าแรก → สำหรับครูฝึก → เปิดโปสเตอร์ QR)
QR ทั้ง 4 ชุดสร้างจากที่อยู่เว็บจริงให้เอง กด **พิมพ์ / บันทึก PDF** (กระดาษ A4, ระยะขอบ: ไม่มี, เปิด "กราฟิกพื้นหลัง")
เติมชื่อหลักสูตรและรุ่นด้วยปากกาในบรรทัดที่เว้นไว้

## การใช้งานประจำ

**ผู้รับการฝึก** สแกน QR → กรอกยศ ชื่อ-สกุล เลขที่ → กรอกรหัสภารกิจ → ฝึก คะแนนส่งเอง
ไม่มีสัญญาณระหว่างฝึกก็ฝึกต่อได้ ระบบเก็บไว้แล้วส่งเมื่อกลับมาออนไลน์

**ครูฝึก** ดูคะแนนใน Google Sheet ได้ทันที

| แผ่นงาน | เนื้อหา |
| --- | --- |
| `สรุป-แบบฝึก` | 1 แถวต่อคนต่อชุด คะแนนดีที่สุด ร้อยละ ผ่านกี่โมดูล คะแนนรายโมดูล |
| `สรุป-เกม` | 1 แถวต่อคนต่อชุด คะแนน ร้อยละ ภารกิจที่ผ่าน ดาว Score-O |
| `ภาพรวม` | จำนวนผู้ส่ง ร้อยละเฉลี่ย ผ่าน 80% ต่ำกว่า 60% สูงสุด ต่ำสุด แยก 4 ชุด |
| `บันทึกทั้งหมด` | ทุกครั้งที่ส่ง ไว้ตรวจย้อนหลัง |

ร้อยละ = คะแนน ÷ คะแนนเต็ม × 100 · สีเขียว ≥ 80 · สีแดง < 60
คอลัมน์ **ตรวจสอบ** = "ถูกต้อง" เมื่อรหัสตรวจสอบตรงกับคะแนน ถ้าขึ้น "รหัสไม่ตรง" ให้เรียกดูหน้าจอของคนนั้น

**รุ่นใหม่** ใน Google Drive คลิกขวาไฟล์ชีต → **ทำสำเนา** เก็บไว้เป็นของรุ่นเก่า แล้วลบแถวข้อมูลในไฟล์เดิม (เก็บแถวหัวตาราง)
ประกาศรหัสภารกิจใหม่ เพื่อให้รุ่นใหม่ได้แผนที่ใหม่

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
| --- | --- |
| แอปขึ้น "ครูฝึกยังไม่ได้ตั้งค่าที่อยู่ส่งคะแนน" | ใส่ `SCRIPT_URL` ใน `config.js` แล้วอัปโหลดไฟล์นั้นใหม่ |
| ทดสอบการเชื่อมต่อไม่ผ่าน | URL ต้องลงท้าย `/exec` และตั้ง "ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน" |
| ขึ้น "ยังส่งไม่สำเร็จ" | ตรวจอินเทอร์เน็ตมือถือ แล้วกด "ส่งคะแนนตอนนี้" |
| คะแนนหายเมื่อเปิดใหม่ | ต้องเปิดด้วยเบราว์เซอร์เดิม ไม่ใช้โหมดไม่ระบุตัวตน (คะแนนที่ส่งแล้วยังอยู่ในชีต) |
| แก้ไฟล์แล้วมือถือยังเห็นแบบเก่า | ปิดแล้วเปิดหน้าใหม่ 1–2 ครั้ง (แอปโหลดของใหม่เมื่อมีสัญญาณ) |
| แก้ `Code.gs` แล้วไม่มีผล | **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้** (URL เดิมไม่เปลี่ยน) |

## ข้อมูลและความเป็นส่วนตัว

- ข้อมูลที่ส่ง: ยศ ชื่อ-สกุล เลขที่ ชุด รหัสภารกิจ คะแนน และเวลา ไม่มีการเก็บอีเมล ตำแหน่ง หรือข้อมูลเครื่อง
- ข้อมูลอยู่ใน Google Drive ของครูฝึกเท่านั้น ระหว่างฝึก คะแนนเก็บในเบราว์เซอร์ของผู้รับการฝึกเอง
- ใครมี URL ของ Apps Script ส่งข้อมูลเข้าชีตได้ (เหมือนแบบฟอร์มสาธารณะ) จึงมีคอลัมน์ "ตรวจสอบ" ไว้คัดกรอง
